**Branch**: `003-dual-oss-endpoint` | **Date**: 2026-01-06 | **Spec**: [spec.md](spec.md)

## Summary

实现VOD服务使用公网端点(`s3_endpoint`)生成签名URL，而录制管道使用内网端点(`endpoint`)上传文件。

**关键发现**:
- 当前配置值是**错误的**：`endpoint` 配置的是公网地址，`s3_endpoint` 配置的是内网地址（与预期相反）
- 火山引擎TOS端点命名规则：`*.volces.com` = 公网，`*.ivolces.com`（带i）= 内网
- 需要**代码修改 + 配置值修正**

## Implementation Analysis

### Current Configuration Problem

```ini
# config/tos_credentials.ini (当前配置 - 端点值错误!)
[TOS]
endpoint = tos-cn-beijing.volces.com       # ❌ 这是公网! (不带i)
s3_endpoint = tos-s3-cn-beijing.ivolces.com # ❌ 这是内网! (带i)
```

**问题**: 配置值与用途相反
- `endpoint` 用于上传，应该是内网，但配置的是公网
- `s3_endpoint` 用于VOD URL，应该是公网，但配置的是内网

### Correct Configuration (Target)

```ini
# config/tos_credentials.ini (正确配置)
[TOS]
endpoint = tos-cn-beijing.ivolces.com       # ✅ 内网端点 - 用于上传 (带i)
s3_endpoint = tos-cn-beijing.volces.com     # ✅ 公网端点 - 用于VOD URL (不带i)
```
